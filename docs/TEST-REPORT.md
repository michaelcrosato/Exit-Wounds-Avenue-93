# Verification report — Exit Wounds Avenue-93

**Status on 2026-10-16: release acceptance remains open.** This report describes the current working tree and the evidence retained in this repository. It supersedes the earlier snapshot in [TEST-REPORT-HISTORY.md](TEST-REPORT-HISTORY.md). The contract is [design.md](../design.md); the milestone view is [PROGRESS.md](PROGRESS.md). The user removed touch-gameplay completion and accepted a standard-mapped Gamepad API emulator because no physical controller is available. Emulation can verify the game's controller path, but it cannot establish physical pad feel, HID detection, cable/Bluetooth behavior, rumble or latency.

The public [repository](https://github.com/michaelcrosato/Exit-Wounds-Avenue-93) has two relevant code revisions. **`e6cd7524f8f1552be87aa20226848641bd1d0fd3`** passed the full public fresh-clone V10 package check in [release reproduction](RELEASE-REPRO.md). The newer published **`e6426f64a18dcb9ae77e324e0c37b480afce84b6`** adds app-side Rapier body-lifecycle protection and a Three r182 quality/shadow adapter. Current-source unit/core tests, WebGL2/WebGPU quality switching and an emulated controller route pass; the patched keyboard, endurance and full public-clone release reruns are tracked separately. Do not use e6's full-route or V10 result as proof for e642.

## Method and current results

The production path uses the pinned my-3d2dge 0.46.1 full engine and 3D module, Three r182 and Rapier 0.19.3. Browser diagnostics on the development build may read `window.__exitWounds`; the packaged build strips that hook, and its smoke uses public UI and keyboard input. End-to-end route runners use normal controller/keyboard/menu actions and the engine's own poller and fixed-step clock. Some focused diagnostics **stage a serialized state or actor positions** to isolate a condition; they are identified below and do not count as ordinary-play progress. Accelerated fixed stepping proves functional reachability, not wall-clock pacing or continuous audiovisual motion.
